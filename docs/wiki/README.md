# Wiki sources

These files are the source of the [AI Friend wiki](https://github.com/filasik/ai-friend/wiki). Edit them here, not in the wiki: the `Wiki` workflow (`.github/workflows/wiki.yml`) copies this folder to the wiki on every push to `main` that changes it, and overwrites edits made in the web UI.

Page links use wiki names (`[Configuration](Configuration)`), so they work on the wiki, not in this folder.
